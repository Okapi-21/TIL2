## 組み合わせ論理回路

------

#### Setp1 用語理解

- 論理素子：演算を行うための最小の回路のこと（論理ゲート、ゲートとも呼ばれる）

  |             ゲート             |                        説明                         |    論理式     |
  | :----------------------------: | :-------------------------------------------------: | :-----------: |
  |    論理積素子（ANDゲート）     |         入力A,Bがともに１の時だけ出力Yが１          |     A・B      |
  | 否定的論理積素子（NANDゲート） |          入力A,Bがともに１の時だけ出力Yが0          |  NOT（A・B）  |
  |     論理和素子（ORゲート）     | 入力A,Bの少なくともどちらか一方が１であれば出力Yが1 |     A + B     |
  | 否定的論理和素子（NORゲート）  | 入力A,Bの少なくともどちらか一方が１であれば出力Yが0 | NOT（A + B）  |
  | 排他的論理和素子（XORゲート）  | 入力A,Bが異なるとき、出力Yが１, 同じとき、出力Yが0  |    A XOR B    |
  |   論理一致素子（NXORゲート）   |  入力A,Bが異なるとき、出力Yが0, 同じとき、出力Yが1  | NOT( A XOR B) |
  |    論理否定器（NOTゲート）     |              入力Aが１ならYは0, 0なら1              |     NOT A     |

  

- 論理回路：論理素子の組み合わせで構成される回路のこと

- 組み合わせ論理回路：入力に対して出力が一意に決まる論理回路のこと
